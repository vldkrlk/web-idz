Нескінченна кількість людських історій.

  • Досьє / 001

    Небо / Грім / Влада

    Зевс

    Володар Олімпу, хранитель порядку й повелитель блискавок.
  • Досьє / 002

    Мудрість / Стратегія / Ремесла

    Афіна

    Богиня мудрості та справедливої війни. Покровителька Афін.
  • Досьє / 003

    Море / Землетруси / Коні

    Посейдон

    Володар морських глибин, чий тризуб здіймає хвилі та бурі.
  • Досьє / 004

    Небо / Світло / Мистецтво

    Аполлон

    Бог світла, пророцтва та музики. Його золота ліра дарує гармонію, а срібні стріли несуть невідворотну кару.
  • Досьє / 005

    Полювання / Місяць / Дика природа

    Артеміда

    Володарка лісів та захисниця диких звірів. Неперевершена мисливиця, чий срібний лук сяє під світлом нічного неба.
  • Досьє / 006

    Любов / Краса / Пристрасть

    Афродіта

    Найпрекрасніша з богинь, що народилася з морської піни. Вона керує серцями смертних і богів, даруючи любов та натхнення.
  • Досьє / 007

    Війна / Руйнування / Відвага

    Арес

    Несамовитий бог кривавих битв і військового шаленства. Його обладунки палають у вогні війни, а меч не знає жалю до ворогів.
  • Досьє / 008

    Вогонь / Ковальство / Ремесла

    Гефест

    Майстерний коваль і володар підземного вогню. У своїх розпечених горнах він кує непереможну зброю та величні палаци для богів.
  • Досьє / 009

    Мандри / Торгівля / Хитрість

    Гермес

    Прудконогий вісник богів у крилатих сандаліях. Провідник душ у підземне царство, покровитель купців, мандрівників та винахідників.
  • Досьє / 010

    Родючість / Врожай / Земля

    Деметра

    Велика мати та хранителька життя на землі. Вона дарує людям щедрі врожаї, а її смуток здатний занурити весь світ у зимовий сон.
  • Досьє / 011

    Сім’я / Шлюб / Материнство

    Гера

    Велична цариця Олімпу та законна дружина Зевса. Покровителька священних союзів, яка ревно оберігає закони шлюбу та вірності.
  • Досьє / 012

    Вино / Радість / Театр

    Дионіс

    Бог виноробства, екстазу та життєвих сил. Він приносить людям веселощі, звільняє від турбот і вчить цінувати кожну мить земного буття.
