# ЕФІР — космічний атлас міфів

Багатосторінковий вебсайт про давньогрецьку міфологію.

## Про проєкт

Сайт складається з чотирьох сторінок:

| Сторінка | Файл | Зміст |
|---|---|---|
| **Атлас** (головна) | [index.html](index.html) | Вступ, космогонія «Спочатку був Хаос», хронологія від Хаосу до героїв, форма підписки |
| **Боги** | [gods.html](gods.html) | Галерея 12 олімпійських богів із зображеннями та короткими описами |
| **Міфи** | [myths.html](myths.html) | Міфи про героїв (Тесей, Орфей та ін.) з динамічним перемиканням статей |
| **Бібліотека** | [library.html](library.html) | Слайдер зі статтями: Гесіод, Медуза, Ікар |

**Технології:** HTML5, CSS3, ванільний JavaScript, Google Fonts (Inter, Lora).

**Можливості:**
- адаптивна верстка (десктоп, планшет, мобільні) з бургер-меню;
- динамічна підміна контенту статей на сторінках «Міфи» та «Бібліотека»;
- слайдер бібліотеки з кнопками та свайпами на сенсорних екранах;
- валідація форми підписки на головній сторінці.

### Структура

```
.
├── index.html          # Головна — «Атлас»
├── gods.html           # Боги Олімпу
├── myths.html          # Міфи та герої
├── library.html        # Бібліотека статей
├── css/
│   ├── base.css        # Змінні, базові стилі, фон, кнопки
│   ├── layout.css      # Шапка, підвал, контейнери
│   ├── home.css        # Стилі головної сторінки
│   ├── gods.css        # Стилі сторінки «Боги»
│   ├── myths.css       # Стилі сторінки «Міфи»
│   ├── library.css     # Стилі сторінки «Бібліотека»
│   └── responsive.css  # Медіазапити
├── js/
│   ├── main.js         # Бургер-меню, форма, спільна логіка
│   ├── myths.js        # Дані та перемикання міфів
│   └── library.js      # Дані статей і слайдер
└── assets/             # Зображення, текстура мармуру
```

## Change Log

### Правка замовника №1 — оформлення фону та кнопок

> **Забаганка замовника:** «Нам подобається макет, але він занадто простий. Зробіть фоном усіх 4 сторінок анімоване золоте сяйво або текстуру мармуру, а всі кнопки зробіть з об'ємним градієнтом та золотою рамкою.»

**Рішення:**
- **Фон.** Обрано варіант із текстурою мармуру: зображення [assets/marble.jpg](assets/marble.jpg) підключено як фон `body` у [css/base.css](css/base.css), тому воно автоматично застосовується на всіх чотирьох сторінках. Текстура масштабується на всю ширину екрана й повторюється по вертикалі.
- **Кнопки.** Перероблено базовий компонент `.btn` у [css/base.css](css/base.css):
  - `.btn--primary` — об'ємний вертикальний градієнт (`linear-gradient` між акцентними кольорами), золота рамка та м'яке світіння (`box-shadow`), підсвічування при наведенні;
  - `.btn--outline` — напівпрозорий темний фон із золотою рамкою та золотистим підсвічуванням при наведенні.

  Оскільки всі кнопки сайту використовують спільні класи, зміни застосовано до кожної кнопки на всіх сторінках.
